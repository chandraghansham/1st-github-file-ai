# HomeEase Services — Demo Website

A responsive home-services landing page built with plain HTML, CSS and JavaScript.

## Included services
- Electrician
- Plumbing
- Home Cleaning
- Pest Control

## Features
- Responsive layout for desktop, tablet and mobile
- Mobile navigation menu
- Service cards that preselect the booking form service
- Front-end demo booking form with basic required-field validation
- No build tools or dependencies required

## Run locally
1. Download or extract this folder.
2. Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

## Important demo notes
- The booking form is front-end only. It does not send or store requests.
- Replace the demo brand name and copy with your own business details.
- Google Fonts requires an internet connection; system fonts will be used if unavailable.
- Add a backend or trusted form service before using this for real customer bookings.
